# navigation
pwd
ls -la
cd

# file & dir
mkdir test_dir
touch test_file.txt
mv test_file.txt test_dir/
cp test_dir/test_file.txt .
rm -rf test_dir

# permissions
chmod +x myscript.sh
chmod 755 myscript.sh


## Answers
pwd: this prints the current working directory.
ls -la: this list the files/directories and their details/permission.
cd: this enables us to change directory.
mkdir: allows us to make directory.
touch: helps us to create new files.
mv: means Move, so it helps us to move.
cp: this also means copy , it makes it possible to copy files.
rm -rf: rm means to remove(delete) the -rf flag is used when a directory has file (not empty).chmod +x: this command makes file executeable.
chmod 755: this command gives only Admin the authority to manipulate such file.
